# ToroTreinta Sportswear — vista de prueba

Esta carpeta contiene únicamente la versión estática preparada para GitHub Pages: `index.html`, hojas de estilo, JavaScript y recursos visuales. El panel ADMIN de demostración fue retirado de esta copia. La aplicación interna no forma parte del paquete.

Para habilitar GitHub Pages, subí estos archivos a la raíz de un repositorio y seleccioná `Deploy from a branch` → `main` → `/(root)` en Settings → Pages.
